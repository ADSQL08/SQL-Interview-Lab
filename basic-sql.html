01

SELECT — Retrieve Records

Display all employee details.

⌄

Business Question

How can we retrieve every employee record?

SQL Query

SELECT *
FROM employees;

Explanation

SELECT retrieves information. The * symbol represents all columns. FROM specifies which table to read.

Expected Result

All five employee records are returned.

02

WHERE — Filter Records

Find employees in the IT department.

⌄

Business Question

Which employees work in IT?

SQL Query

SELECT *
FROM employees
WHERE department = 'IT';

Explanation

WHERE filters records according to a condition. Only employees whose department is IT are returned.

Expected Result

Ravi, Arjun and Kiran.

03

DISTINCT — Unique Values

Find all different departments.

⌄

Business Question

Which departments exist in the company?

SQL Query

SELECT DISTINCT department
FROM employees;

Explanation

DISTINCT eliminates repeated values from the query result.

Expected Result

IT, HR and Finance.

04

ORDER BY — Sort Results

Display salaries from highest to lowest.

⌄

Business Question

Who earns the highest salary?

SQL Query

SELECT emp_name, salary
FROM employees
ORDER BY salary DESC;

Explanation

ORDER BY sorts query results. DESC means descending order, from highest to lowest.

Expected Result

Arjun — 75000, Ravi and Kiran — 60000, Sneha — 50000, Priya — 45000.

Ravi and Kiran have equal salaries, so their relative order is not guaranteed.

05

AND — Multiple Conditions

Find IT employees earning above 60000.

⌄

Business Question

Which IT employees earn more than ₹60,000?

SQL Query

SELECT emp_name, salary
FROM employees
WHERE department = 'IT'
AND salary > 60000;

Explanation

AND combines multiple conditions. Both conditions must be satisfied.

Expected Result

Arjun — 75000.

06

COUNT — Count Records

Find the total number of employees.

⌄

Business Question

How many employees are in the company?

SQL Query

SELECT COUNT(*) AS total_employees
FROM employees;

Explanation

COUNT(*) counts the number of rows. AS gives the result column a name.

Expected Result

total_employees = 5

07

GROUP BY — Summarize Records

Count employees in each department.

⌄

Business Question

How many employees work in each department?

SQL Query

SELECT department,
       COUNT(*) AS employee_count
FROM employees
GROUP BY department;

Explanation

GROUP BY groups records based on department. COUNT(*) then counts the rows in each group.

Expected Result

IT = 3, HR = 1, Finance = 1.

08

HAVING — Filter Groups

Find departments with more than 2 employees.

⌄

Business Question

Which departments contain more than two employees?

SQL Query

SELECT department,
       COUNT(*) AS employee_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 2;

Explanation

HAVING filters groups after GROUP BY has summarized the data.

Expected Result

IT — 3 employees.

09

INNER JOIN — Combine Tables

Find each employee's office location.

⌄

Business Question

How can we display employees with their department locations?

Additional Departments Table

department location
ITHyderabad
HRMumbai
FinanceBengaluru

SQL Query

SELECT e.emp_name,
       e.department,
       d.location
FROM employees e
INNER JOIN departments d
ON e.department = d.department;

Explanation

INNER JOIN combines matching records from two tables. Here, department is the common matching column.

Expected Result

Ravi — Hyderabad
Priya — Mumbai
Arjun — Hyderabad
Sneha — Bengaluru
Kiran — Hyderabad

This query requires an additional departments table. It is a learning example and is not yet supported by the existing five free SQL labs.
10

Subquery — Second-Highest Salary

Find the second-highest distinct salary.

⌄

Business Question

What is the second-highest distinct salary in the company?

SQL Query

SELECT MAX(salary) AS second_highest_salary
FROM employees
WHERE salary < (
    SELECT MAX(salary)
    FROM employees
);

Explanation

The inner query finds the highest salary. The outer query finds the maximum salary below it.

Expected Result

second_highest_salary = 60000
